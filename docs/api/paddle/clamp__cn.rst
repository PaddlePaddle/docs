clamp\_
-------------------------------

.. py:function:: paddle.clamp_(x, min=None, max=None, name=None)

``clip_`` 的别名，请参考 :ref:`cn_api_paddle_clip_`。

.. note::
    别名支持：参数名 ``input`` 可替代 ``x``，如 ``clamp_(input=tensor_x)`` 等价于 ``clamp_(x=tensor_x)``。
